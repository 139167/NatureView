# NatureCore Architecture

NatureView 的首要边界是静态世界定义与动态自然状态分离。

```text
WorldDefinition
  地形、河流、生物群系、铁路等静态规则结果
          |
          v
NatureSimulation
  时间、天气、风、光照、水文与事件
          |
          v
Unified Snapshot
          |
     +----+----+
     |         |
 Renderer    Audio
```

## Invariants

1. 静态世界由 seed 唯一确定。
2. 动态自然使用 20 Hz 固定 tick；渲染帧率不改变模拟结果。
3. 渲染器、音频和相机只读取同一模拟状态。
4. 视觉粒子与声音不能创建独立随机风场。
5. 核心不依赖图形 API、窗口系统或音频设备。
6. 软件预览只读取核心快照，不向核心写回渲染状态。
7. 相邻地形块边界必须复用完全相同的世界采样顶点。
8. Windows 图形宿主拥有 DXGI/D3D12 资源；核心与渲染场景保持平台无关。
9. macOS 图形宿主拥有 AppKit/Metal 资源；跨平台共享网格与状态，不共享 GPU 调用。
10. HDR 渲染、曝光与色调映射只消费统一的太阳、云和雾状态。
11. 方向光阴影必须使用同一太阳方向，不能由渲染器另建光源。
12. 天空和水面反射复用同一大气辐射近似，避免天空与倒影色温割裂。
13. 极光活动由纬度、夜间、云量与确定性天气信号共同决定；渲染器不得独立随机触发极光。
14. 极光多层发射必须在 HDR 空间积分后再统一曝光与色调映射。
15. 声音的幅度、阵风、河流流量和声像必须由同一环境与相机状态派生。
16. 实时音频回调不得分配内存；参数通过原子目标值传入并在采样级平滑。
17. Metal 窗口退出时必须停止音频后端；画面和声音共用同一模拟帧推进。
18. 树木位置来自静态世界规则，风摆与树影必须读取同一 `EnvironmentState`。
19. HDR 后处理必须保留线性光照，Bloom 与色彩分级只能在 tone mapping 阶段进入显示空间。
20. SSAO 必须读取同一场景深度缓冲，并在 Bloom 与色调映射前合成。
21. 屏幕空间水面反射读取当前帧不透明场景副本；无有效命中时必须回退到天空反射。
22. 天空云层与地表云影必须由同一云量、时间和噪声规则驱动。
23. 水面折射读取当前帧不透明场景副本；水体不能采样自身颜色形成反馈。
24. 地形湿润度和树木局部高度通过顶点辅助通道传给材质 shader，不单独生成随机表面状态。
25. 森林原型必须按类型分组实例化；风摆、阴影和材质使用同一实例变换。
26. 森林密度由确定性地形约束与低频林分场共同决定，树木单个随机值不能覆盖整体林分结构。
27. 叶片卡片的颜色遮罩与阴影遮罩必须复用同一程序化 alpha 规则，禁止矩形全实心投影。
28. 程序化纹理资产必须由 seed 决定、可平铺，并以 RGBA8 数据契约进入各平台渲染宿主。

## Current Scope

当前已证明世界生成、环境规则、相机路径、确定性、Metal 场景绘制、HDR 天空、程序化云层与云影、5×5 PCF 阴影、SSAO、水面屏幕空间反射与水深折射、多层 HDR 极光、针阔混合实例化森林、树冠透光、近景草岩土与湿岸材质、HDR Bloom 与色彩分级、确定性离线声景映射、Mac 实时音频输出，以及 Metal/音频联合生命周期。

明确不包含：

- 高密度森林 LOD、叶片透光、细枝、草地、精确表面透射、局部平面反射、完整球面极光大气散射和 GI；
- 现场录音素材、空间声源、遮挡、混响和最终混音；
- Windows 可绘制交换链或桌面壁纸宿主；
- 铁路、列车、天气事件编辑和美术资源管线。

## Next Seam

继续完善植被细节、Metal 光照与水面，再接入现场录音和空间音频。DX12 在 Mac 宿主稳定后复用同一快照与网格契约。若渲染需要高频风场，GPU 表现层可从快照频率和相位重建细节，但低频风矢量必须来自 `EnvironmentState`。
